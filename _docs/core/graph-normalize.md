## 1. Overview & Purpose
| Component | Source File |
| :--- | :--- |
| **graph-normalize.ts** | [core/graph-normalize.ts](/core/graph-normalize.ts) |

This component is responsible for taking raw graph data, typically generated by a loader, and cleaning it up into a canonical, usable structure. Its primary responsibility involves merging duplicate nodes (where a file appears both as a source and a target in different forms), resolving internal documentation links, and ensuring the graph structure is consistent and free of self-references or redundant edges.

It acts as a critical post-processing layer within the application's data pipeline. It consumes the raw `GraphData` structure and outputs a `NormalizeReport`, providing metrics on the cleanup process. This function is essential for ensuring that subsequent graph traversal and analysis components, such as those relying on [createNodeResolver](/core/graph-normalize.ts), operate on a reliable and deduplicated dataset.

## 2. Public API & Interfaces
| Entity | Type | Description |
| :--- | :--- | :--- |
| `DOC_RELATION` | Constant | A string constant used to denote dependencies explicitly listed within a node's markdown documentation. |
| `NormalizeReport` | Interface | Defines the structure for reporting the results of the graph normalization process, including counts of merged duplicates, added links, and unresolved references. |
| `linkEnd` | Function | A utility function that safely extracts the ID from a link source or target, whether it is a string or a `GraphNode` object. |
| `isPlaceholder` | Function | Checks if a given `GraphNode` is a placeholder node, identified by a specific group and the absence of raw markdown content. |
| `normalizeRef` | Function | Cleans and strips prefixes from a reference string (like a file path), converting it into a canonical, relative identifier used for internal mapping. |
| `createNodeResolver` | Function | Builds and returns a resolver function capable of mapping a markdown link (label and href) to a specific `GraphNode` instance, prioritizing real nodes over placeholders. |
| `refSegments` | Function | Parses a document link's href to extract an array of path segments, useful for hierarchical navigation. |
| `normalizeGraphData` | Function | The main entry point; it processes the entire `GraphData`, performing duplicate merging, adding inferred doc links, and dropping invalid edges, returning a `NormalizeReport`. |
| `countConnections` | Function | Iterates over the graph's links to calculate the total number of incoming and outgoing connections for every node, updating the `connectionCount` property on each node. |

## 3. Implementation Details & Side Effects
- **Core Logic:** `normalizeGraphData` first identifies and remaps placeholder nodes to their real file counterparts, updating all associated links. It then scans node markdown for `**Internal:**` sections, using `createNodeResolver` to find targets. If a target is found and is not already linked, a new link is added. Finally, it filters the link array to remove self-loops and exact duplicates. `countConnections` uses a frequency map to tally connections for every node.
- **Side Effects:** Mutates the input `GraphData` object (`data.nodes` and `data.links`) in place during `normalizeGraphData` and `countConnections`.
- **Error Handling:** `createNodeResolver` handles ambiguity by returning `null` if a link could resolve to multiple nodes or none. `normalizeGraphData` collects unresolved document references into the `unresolvedDocRefs` array within the `NormalizeReport` instead of throwing errors.
